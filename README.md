## 项目简介

FreeRPA（风影RPA） 是一款基于 Electron 的桌面端自动化工具，将 **可视化流程编排**、**AI 自然语言搭建**、**指纹浏览器环境**、**Deno 安全沙箱** 与 **可安装插件系统** 融为一体，覆盖网页、数据、文件、Excel、数据库与网络等全场景，无需编写代码即可构建并运行复杂的自动化流程。

- **官网**：https://freerpa.cn
- **数据**：默认保存在本地 SQLite，离线可用、隐私可控
- **平台**：Windows / macOS / Linux

## 核心特性

### 🎨 可视化流程编排
- 基于画布的**拖拽式**节点编排，所见即所得
- 节点支持版本化管理（`V1/V2…`），历史工作流自动兼容
- 完整的撤销 / 重做、复制 / 粘贴、自动布局、自动连线、子流程嵌套
- 运行前**一键检测**：缺节点、未连接、必填输入、参数引用、子流程结构等自动定位

### 🤖 AI 自然语言搭建
- 在画布旁直接对话，用自然语言描述需求，AI **自动创建 / 连接 / 配置节点**
- 支持 OpenAI 兼容 / Anthropic / Google 等多供应商、多模型
- AI 每次改动后自动做工作流可执行性检测，发现问题主动修正
- 内置工具循环守卫（防死循环、失败重试、上下文预算），稳定可靠

### 🌐 指纹浏览器环境
- **内核随包内置**（Chromium），无需额外下载，开箱即用
- 支持浏览器指纹（平台、时区、语言、UA）、代理、无头模式
- 页面操作全部由节点驱动：打开/访问、点击、输入、滚动、截图、取内容、下载/网络/请求监听等

### 🔒 Deno 安全沙箱
- 工作流执行在 **Deno Worker 沙箱** 中运行，遵循**最小权限原则**
- 文件系统、网络、子进程、环境变量、系统信息等权限**逐项可配**
- 沙箱内无法访问用户未授权资源，最大限度保护本机安全

### 🧩 可安装插件系统
- 支持安装 / 卸载 / 打包本地插件，插件即一个可分发的小型模块
- 插件可贡献**自定义节点**、表单配置与执行逻辑，扩展无限能力
- 插件市场：https://freerpa.cn/plugins

## 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                        渲染进程 (Vue 3)                        │
│   流程画布 · AI 对话面板 · 数据管理 · 浏览器管理 · 设置          │
└──────────────────────────┬──────────────────────────────────┘
                           │ Electron IPC (preload 桥)
┌──────────────────────────▼──────────────────────────────────┐
│                        主进程 (Node.js)                       │
│  窗口/托盘/菜单 · IPC 注册 · SQLite 数据层 · AI 聊天引擎         │
│  浏览器内核管理 · 插件系统 · 统计上报                            │
└──────────────────────────┬──────────────────────────────────┘
                           │ JSON 行协议 (stdin/stdout)
┌──────────────────────────▼──────────────────────────────────┐
│                    Deno 宿主 + 工作流 Worker                   │
│   每个工作流独立 Worker（最小权限沙箱）· 节点执行器 · RPC 桥     │
└──────────────────────────┬──────────────────────────────────┘
                           │ CDP (Chrome DevTools Protocol)
┌──────────────────────────▼──────────────────────────────────┐
│                   指纹浏览器内核 (Chromium)                    │
└─────────────────────────────────────────────────────────────┘
```

- **数据层**：SQLite（本地库），模型/工作流/浏览器/元素集/分类等统一 CRUD 抽象
- **AI 层**：主进程 `ai` SDK 流式补全，渲染进程组装上下文与工具循环
- **执行层**：Deno Worker 内动态加载节点执行器，权限由主进程按用户配置生成
- **浏览器层**：puppeteer-core 通过 CDP 连接内置内核，页面操作在 Worker 内完成

## 快速开始（开发）

### 环境要求

- **Node.js** ≥ 22
- **Yarn** 1.x
- （打包 Windows 需对应平台或 CI）

### 安装与运行

```bash
# 安装依赖（postinstall 自动下载 Electron 二进制、构建原生依赖）
yarn install

# 启动开发模式（含调试端口 9229）
yarn dev
```

### 常用脚本

```bash
yarn lint                # ESLint 检查
yarn format              # Prettier 格式化
yarn build               # electron-vite 构建（主进程 + 渲染进程）

yarn test:worker         # Deno 引擎冒烟测试（全链路：宿主→Worker→引擎→节点）
yarn test:worker-permissions  # Worker 权限专项测试

yarn fetch:deno          # 下载 Deno 运行时
yarn build:worker        # 构建 Worker 运行时资源（节点执行器 + 依赖闭包）
yarn ensure:native       # 校验原生依赖（sqlite3 等）
```

### 打包分发

```bash
yarn build:mac           # macOS 安装包
yarn build:win           # Windows 安装包（NSIS）
yarn build:linux         # Linux（AppImage/snap/deb）
yarn build:unpack        # 免安装目录（快速验证）
```

打包前会统一执行 `ensure:native → fetch:deno → build:worker → build`，确保 Deno 二进制、Worker 资源与原生依赖就绪。

## 数据与隐私

- 所有业务数据（工作流、数据模型、浏览器环境、AI 会话、系统配置）默认存储在本地 SQLite
- 导出格式：工作流 `.frw`、浏览器 `.frb`、数据表 `.frm`、元素集 `.fre`（均带版本校验与压缩）
- 内置轻量**日活/使用时长统计上报**（设备 ID + 平台 + 版本），用于改进产品；可在设置中关闭，失败不影响使用
- AI 对话中涉及的工作流配置会做**敏感字段脱敏**，避免密钥类明文发送给第三方模型
