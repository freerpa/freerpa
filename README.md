## 项目简介

FreeRPA（风影RPA） 是一款基于 Electron 的桌面端自动化工具，将 **可视化流程编排**、**AI 自然语言搭建**、**指纹浏览器环境**、**Deno 安全沙箱** 与 **可安装插件系统** 融为一体，覆盖网页、桌面、手机、数据、文件、Excel、数据库与网络等全场景。

- 官方网址：**https://freerpa.cn**
- 数据默认保存在本地（SQLite），离线可用、隐私可控
